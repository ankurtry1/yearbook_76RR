# Yearbook V2 Product Spec

## Modes
- Write (default)
- Read

## Write mode
### Desktop
- Scrapbook cloud hybrid
- Slight overlap
- Inline expanded composer on selected card
- Search from 2 characters
- Recipient can only be selected from roster-backed suggestions

### Mobile
- Story-style clustered discovery
- Search from 2 characters
- Bottom sheet composer
- Returns to deck after send
- Encourage writing another

## Read mode
- Playful wall of cards
- Each card = one memoir from one person
- Card flips open
- Sender photo remains visible unless memoir is anonymous
- Anonymous memoirs show placeholder silhouette + Anonymous label
- Sorts: random, unread, newest

## Rules
- Multiple memoirs allowed per sender-recipient pair
- No edit
- No delete
- No drafts in V2
- No moderation in V2
- Immediate visibility
- Backend hard cap 10,000 chars
- Reactions only: love, laugh, emotional, anchored
- Reaction should eventually notify the memoir author

## Auth
- Pre-seeded roster only
- Email OTP only
- No public signup
- First successful login activates profile
